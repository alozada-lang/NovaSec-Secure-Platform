# 🛡️ NovaSec Consulting - Secure Platform

Este proyecto es una plataforma web desarrollada en **Java EE** con una base de datos **MySQL**, enfocada en la implementación de controles de seguridad informática avanzados.

## 🚀 Características de Seguridad (ASI)
* **Cifrado Asimétrico:** Implementación de algoritmos RSA para protección de datos.
* **Seguridad Perimetral:** Configuración de WAF para mitigar ataques SQLi y XSS.
* **Autenticación:** Sistema de Doble Factor (2FA) integrado.
* **Criptografía:** Uso de Esteganografía (Stools) para el ocultamiento de mensajes críticos.

## 🛠️ Tecnologías Utilizadas
* **Lenguaje:** Java (NetBeans IDE)
* **Base de Datos:** MySQL (XAMPP)
* **Gestión:** Jira Software & GitHub
* **Conectividad:** Túneles seguros mediante Ngrok

## 📋 Requisitos de Instalación
1. Importar el archivo `db_novasec.sql` en PHPMyAdmin.
2. Abrir el proyecto en NetBeans.
3. Configurar el servidor GlassFish/Apache Tomcat.
